<h1 align="center">BIM KML &amp; Tracker Generator</h1>

<p align="center">
  Convert Excel and CSV coordinate tables into Google Earth KML files and filtered Excel trackers directly on Android.
</p>

---

## Main Features

- **Excel & CSV Loader:** Import `.xlsx`, `.xls`, and `.csv` files directly from your device storage.
- **Automatic Coordinate Detection:** Automatically identifies `Latitude` (`lat`) and `Longitude` (`lon`/`lng`) columns, with manual dropdown overrides.
- **Flexible KML Placemark Formatting:** Select one or more columns for **KML Name Columns** and **KML Description Columns** (joined cleanly with ` - `).
- **Dynamic Searchable Filters:** Add multiple column filters with a searchable multi-select checklist (`Select All`, `Clear Filter`, and live matching row count).
- **Separate File Splitting:** Enable **Create Separately** on any filter (or globally) to automatically generate one `.kml` or `.xlsx` file per filter-value combination.
- **Live Data Preview:** Inspect up to 25 filtered rows in-app before exporting.
- **Native Android Downloads:** Exports `.kml` and `.xlsx` files directly into your phone's `Downloads` folder.

---

## How to Use

1. Tap **Load Excel / CSV File** (or **Load Sample Data** to test).
2. Select the columns you want for **KML Name Columns** and **KML Description Columns**.
3. Verify the **Latitude Column** and **Longitude Column** dropdowns.
4. *(Optional)* Tap **+ Add Filter** to filter rows by specific column values or split outputs into separate files.
5. Tap **Create KML** for a Google Earth `.kml` file, or **Create Tracker (.xlsx)** for a filtered Excel spreadsheet.
